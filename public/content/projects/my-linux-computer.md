# The background

Welp as the title already said, I use linux. I'm a late generation of internet, the first ever OS I use is not MSDOT or anything such that old. But it's the good old **WindowXP**.

As a person that stick with Microsoft since knowing how to read, I must say I made a love - hate deeply bond with Windows.

I used through multiple Windows version such:

- Windows XP
- Windows Vista
- Windows 7
- Windows 8 (why they even do this)
- Windows 10
- Windows 11

And base on that history, I must have be like anybody else in my country by keep just using Windows.

But for some reasons, one day I decided making a very **BOLD** move. Without hesitation, I get my USB, burn the first ever linux distro .ISO and overwrite my disk.

# The journey starting point

Till now, 2026-09-16, I been using linux for 2 years and 28 days (since 2024-08-19). I had tried couple distro, differents working environment, stepped on multiple mistake and learnt multiple value lesson. To be fair, if I have some words atm im writting this blog about my journey since I first ever touching the computer. I would say:

> Trademark of myself to the world wasn't that meaning-less. There're multiple things to learn, and multipe mistake to forgive. But after all, they all combined to become me.

The journey of me and linux starting with the very first .ISO that I burn into my USB. The good old **Fedora KDE Plasma**. Back then, I'm a person that knowing nothing about Linux than the Tux Penguin. So I decided to join Linux Community discord and ask professional there a very common question that everyone would ask.

`Hi, I'm new to linux. What version of it should I use?`

Haha, looking back then. Such it a hilarious but cute question. And I'm a very lucky person when coming to the right places. Member in that discord server didn't blame me or going hard on me at all. They were kinda chill, explain to me about GNU/Linux, about distro, etc.

And after discuss with people in the server and go thru a quick search up. I burn the .ISO and install overwrite my Windows 11 at that time, leaving myself no way to go back.

My first impression with Linux (or to be fair, with KDE Plasma) is. **Wait, this look easy to use. Not like the myth where linux user have to write 15 commands to install FireFox**.

And after that my second impression is **Holy Shit. Why is it so smooth?**

Love to remembering that momment. But I have to admit that when switch to Linux, things does getting more smooth then when I was using Windows 11.

But my journey sticking with Fedora and KDE Plasma didn't last long. After couple first days impression about Linux. I faced couple problem such

- Discord unable to screen share with my friends.
- I didn't prepare on how to type Vietnamese yet to text with my friends.
- Not knowing any command or never used terminal before.

And learned some about X11 and Wayland. I moved to my next point of the journey, **Debian**

After tinkering with Fedora for good weeks. I decided to hop into Debian because heading it would have more community support, and it stable where I don't have to scare it would brake anytime soon. But I didn't like it really much so I hop to next distro very soon.

And our next distro is **OpenSUSE (TumbleWeed)**

Talking about this bad boy, I really like it. I like the way it have built-in multiple tools for it system. The way I install and use with my NVDIA card effort less at that time. Oh boy I love it.

I been using it for good amount of time, tbf no problem while using it at all.
But then I get bored...

And I come to my current destination, **Arch Linux**.

Oh boy, this. IDK what to say, I just want to say that, It is my love.

The way it let me tinkering everything from scratch.
The way it make me have to take responsibility for every things I done.
The way it let me being me and building a thing that fully **me** in it.

It's just my destiny and I glad because I didn't missed it out.

And I have to say, comparing Arch with other distro I used before, I must give AUR a big shout-out.
